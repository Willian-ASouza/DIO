# GenAI & Dados - Bootcamp DIO

Este repositório contém os projetos e exercícios desenvolvidos durante o bootcamp **GenAI & Dados** da [DIO](https://www.dio.me).

## 📂 Estrutura
- `projetos/` → Projetos práticos do bootcamp
- `exercicios/` → Exercícios e desafios
- `docs/` → Documentação e anotações

## 🚀 Tecnologias utilizadas
- Ferramentas de GenAI
- GitHub
- NotebookLM


## 📌 Objetivo
Aprender e aplicar conceitos de **Inteligência Artificial Generativa** e **Ciência de Dados** em projetos práticos.
